🤖 给 agent 的命令

复制整条命令发给 agent。它会自动注册 MCP、安装 skill，并用这条链接换取一份只属于该 agent的独立凭据。

链接中的票据只用于一次性兑换：10 分钟内有效，且只能使用一次。它放在 URL 的 # 后面，不会随网页请求上传到服务器。

🛡️ 安全说明

  1. 全程不需要、也绝不会索取你的 App 密码。
  2. 换到的是该 agent 专属的 refresh token，仅保存在 agent 所在机器（权限 0600），不会写入本页面或聊天记录。
  3. 可随时在 App 的「操作日志」查看授权与调用记录；需要断开时让 agent 运行 npx -y github:begin2019510/purchase-app-mcp logout。
  4. 建议先只读验证：安装完成后调用 purchase.list，确认无误再授权写操作。
⚠️ 请不要把这条链接发到公开群聊、Issue 或截图里。任何拿到链接的人都能在 10 分钟内、以你的身份完成一次授权。已泄露就在 App 里重新生成，旧链接会立即失效。
