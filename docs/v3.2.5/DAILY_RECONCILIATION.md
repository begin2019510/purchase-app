# 每日对账（2026-12-01 ～ 2026-12-07）

试运行期间每天固定做一次只读对账，回答四个问题：

1. 有没有超年度 / 超月度 800 / 超周六 10%？
2. 台账对账差异是否为 0？
3. 每笔记账动作是否有审计事件、采购单与关联是否一致？
4. 应生成的月度快照是否齐全？

## 命令

```bash
cd /root/purchase-app   # 或生产目录 /opt/purchase-server 的上一级（按部署方式）
node server/scripts/v325-daily-recon.js --date=2026-12-0X \
  --out=/tmp/recon-2026-12-0X.json
```

- 默认对账「今天」（北京时间）。
- 脚本只执行 SELECT，使用 `START TRANSACTION READ ONLY` + `ROLLBACK`，**不写库、不改快照**。
- 退出码：PASS / WARN → 0；FAIL → 1；加 `--strict` 时 WARN 也返回 1（可用于定时任务告警）。

## 结果处置

| 结论 | 含义 | 动作 |
| --- | --- | --- |
| PASS | 全部 19 项检查通过 | 记录归档 |
| WARN | 有非致命项：配置生效时间、逾期、待审批超 48h、已批准未关联、快照缺失等 | 当日跟进，填入 `ISSUE_LOG.md`；不影响继续试运行 |
| FAIL | 超年度/月度/周六上限、对账差异非 0、审计缺口、关联金额不一致等 | 立即停止相关写操作，按 `ISSUE_LOG.md` 升级 P1/P0，并评估回滚 |
