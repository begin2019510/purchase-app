# 试运行额度与确认规则（2026-12）

## 2026 默认配置

| 项 | 值 |
| --- | --- |
| 年度上限 | 1000 |
| 月度常规 | 800 |
| 周六追加率 | 10% → 周六上限 100 |
| 大额阈值 | 800（超过必须走大额采购） |
| 跨年 | 不允许 |
| 生效 | 2026-12-01 |

> 2026 年仅 12 月试运行；12 月之前的历史月份不补算、不追溯。

## 2027 默认配置（预置，2027-01-01 生效）

年度 10000 / 月度常规 800 / 周六追加率 10% / 大额阈值 800 / 允许跨年。

## 额度口径

- 年度占用 = Σ 分期计划金额 − 已释放 − 已退款（按年）。
- 年度剩余 = 年度上限 − 年度占用。
- 月度常规 800：普通申请按批准金额占用；**同月退款恢复当月 800**，跨月/跨年退款不恢复。
- 周六追加：仅周六可申请，按自然日累计，不超过「年度上限 × 10%」。
- 大额：金额超过 800，按分期计划占用年度额度，不占月度 800。

## 年度上限修改与二次确认

- 试运行期间**建议锁定年度上限**；确需修改时：
  - 必须填写修改理由；
  - 必须由**同一账号再次确认**（现设计，非第二人审批）；
  - 每次修改写入 `config_update` 审计事件（操作人、IP、原因、before/after、版本号）。
- 调低不得低于已占用 + 未来承诺（服务端拒绝 `CONFIG_TOO_LOW`）。
- 历史年份配置只读；修改只对当前/未来年度生效。

## 不允许的操作

- 绕过特殊预算页，从采购单直接改金额、退货或取消特殊单。
- 手工改库调整已入账金额、分期状态或审计事件。
- 在开关关闭时写入特殊预算数据。
- 通过共享账号代他人二次确认。
