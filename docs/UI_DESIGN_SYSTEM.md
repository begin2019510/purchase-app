# UI 与动效规范

## 视觉原则

- 中性浅底和白色内容面板构成层级；蓝紫用于主操作、当前导航和焦点状态。
- 信息靠排版、留白与细分隔线区分，阴影只用于浮层或轻度悬浮反馈。
- 保留采购、记账、统计、待办、项目五个入口及现有字段/业务行为。
- 卡片优先呈现名称、金额/状态和一行上下文；辅助信息降低对比度。

## 共享 token

| 类别 | Token | 默认值 |
|------|-------|--------|
| 背景 | `--ui-bg` | `#f5f6fa` |
| 内容表面 | `--ui-surface` | `#fff` |
| 次级表面 | `--ui-surface-2` | `#f1f2f7` |
| 主文字 | `--ui-ink` | `#20212a` |
| 次级文字 | `--ui-secondary` | `#555866` |
| 辅助文字 | `--ui-muted` | `#858896` |
| 强调色 | `--ui-accent` | `#5865d9` |
| 分隔线 | `--ui-line` | `rgba(38,40,52,.09)` |
| 圆角 | `--ui-radius-sm/md/lg` | `12 / 17 / 22px` |
| 阴影 | `--ui-shadow` | 低对比两层阴影 |

页面继续沿用原有字号与组件语义，强化层级：页面标题约 21px、卡片标题 15–17px、正文 14–16px、辅助标签 11–12px。表单输入保持至少 44px 高度，触控目标不依赖悬停状态。

## 模块落地

- **采购**：商品名称和总价优先；状态与分类使用轻量徽标，卡片统一细边、圆角和轻触反馈。
- **记账与统计**：沿用原账目结构和图表，仅统一分组背景、统计卡与筛选分段控件；金额采用等宽数字感的数字字形。
- **待办**：列表卡与项目卡共享表面层级；完成反馈仅作用于勾选控件，不重放整行入场动画。
- **项目详情**：沿用项目阶段信息结构，桌面使用居中详情面板，手机使用贴底 sheet 并保留内部滚动。
- **设置与登录**：圆角分组和分隔线替代厚重阴影；输入焦点用强调色描边与淡色 halo。
- **导航**：桌面显示顶部五项导航；窄屏显示底部五项导航并保留 iOS/Android 安全区。
- **筛选与浏览**：采购、待办、项目、记账和统计的筛选/月份控件使用原生按钮语义，键盘可聚焦并暴露当前选择状态。

## 动效

- 快速反馈 120–150ms；弹层约 230ms；缓动使用 `cubic-bezier(.2,.75,.25,1)`。
- 只对 opacity、transform、背景色和边框色做轻量变化；不动画化模糊滤镜。
- 弹层入场只移动约 12px 并轻微缩放；切换入口沿用已有短淡入；勾选动画只应用于控制件。
- 列表排序/数据刷新不触发整屏重播；长列表不加逐项延迟入场。
- `prefers-reduced-motion: reduce` 下关闭位移、重复动画和滚动平滑。

## 主题、屏幕与端

- 显式暗色模式与系统暗色模式都使用深灰表面、浅色文字和调整后的强调色。
- 页面顶部安全区使用与当前表面一致的背景，底部导航与 sheet 使用 `env(safe-area-inset-*)`。
- 390px 窄屏单列布局，桌面限制内容宽度并避免卡片无限拉宽。
- PWA 与 Capacitor `www/` 使用同一份根目录 HTML/CSS/JS/Service Worker；由 `node scripts/sync-ui.js` 同步。
- Capacitor 原生触觉仍由现有功能能力检测决定，本次没有强制启用设备震动。

## 模块交互结构

- 采购过滤器使用带 `aria-pressed` 的按钮并委托处理状态/分类选择；采购卡的主要详情操作与批量选择、编辑、删除分离，避免可点击容器里嵌套多个操作按钮。
- 待办列表行使用 article 容器，标题/摘要由独立主按钮打开详情，完成按钮单独切换状态。
- 项目卡使用可聚焦的 article，支持鼠标、Enter 与 Space 打开详情。
- 记账明细与统计报告卡使用语义化 section/article，并在可操作卡片上提供键盘激活。
- 采购、记账、待办、项目与报告继续使用既有中文字段和 API 映射；这些交互改造不改变服务器数据契约。
